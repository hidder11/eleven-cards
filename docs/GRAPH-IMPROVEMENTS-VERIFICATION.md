## Limits and known baseline issue

All browser data and Tibber replies are synthetic. The matrix uses local combined bytes; touch tests use local standalone bytes. These are not native Home Assistant theme/editor/integration tests or real-phone verification. No live provider action was called.

At 320px, Energy's long Today/Tomorrow headings already collide/clip in unmodified develop. A baseline screenshot using develop's exact combined bundle reproduced it; this existing issue is not introduced by the port and was left unchanged rather than broadening scope. Tooltip bounds and no-page-overflow assertions still pass; they do not imply those headings fit.

Reproduce with a Python environment containing Playwright and `CHROME` (or `AGENT_BROWSER_EXECUTABLE_PATH`) pointing to an installed Chromium. `GRAPH_OUT` and `TOUCH_OUT` select evidence directories. Reports and genuine screenshots were kept outside Git; no household data or screenshots are committed.
